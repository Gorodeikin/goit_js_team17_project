# ArtistsHUB — CodeWave Team Project

Responsive artist discovery platform built as a team project during the GoIT JavaScript course.

The application allows users to discover artists, browse information about them, view albums and tracks, and interact with artist-related content through a responsive web interface.

## Live Demo

https://iryna-novikova.github.io/goit_js_team17_project/

## Project Overview

ArtistsHUB was developed as a 7-day JavaScript module team project.

The main goal was to build a responsive web application that retrieves data from an external API and dynamically renders artist-related content.

The interface is adapted for mobile, tablet and desktop devices.

## Features

- Artist cards rendered from API data
- Artist genres and descriptions
- Detailed artist information
- Albums and tracks displayed in a modal
- Responsive layout for mobile, tablet and desktop
- Navigation between page sections
- Reviews and feedback functionality
- Loading states
- Interactive `Learn More` controls
- API integration and asynchronous data handling
